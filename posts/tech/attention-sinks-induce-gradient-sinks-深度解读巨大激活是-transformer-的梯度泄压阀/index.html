论文来源：Chen, Y., Lin, Z., & Yao, Q. (2026). Attention Sinks Induce Gradient Sinks: Massive Activations as Gradient Regulators in Transformers. arXiv:2603.17771（v3）. arXiv 页面 · 代码（CC BY 4.0）

前置要求：Transformer 的注意力机制与残差结构，可参考速通 AI（三）：Transformer 架构详解；反向传播的基本概念。RMSNorm 不要求预先了解，正文会从梯度的角度讲到它。

1. 引言：两个老现象，一个新视角#

1.1 两个总在首 token 碰头的现象#

　　Transformer 语言模型里有两个出了名的"怪现象"。第一个叫注意力汇（attention sink）：少数 token，通常是序列的第一个，吸引了与其内容完全不成比例的注意力，后续成百上千个 token 的注意力都往它身上倒。第二个叫巨大激活（massive activation）：同样是在首 token 附近，少数几个通道的激活值大得离谱，比其余激活高出几个数量级。

　　两个现象经常结伴出现，而且都不是无害的奇观。它们牵动长上下文推理、微调稳定性与量化精度，是工程上绕不开的现实问题。更让人在意的是机制上的关联：为什么模型总是把这两个毛病一起学出来？

　　以往的解释大多盯着前向传播。一种流行说法是，softmax 要求注意力权重之和为 1，模型需要一个"什么都不干"的注意力出口，于是把多余的注意力倒进首 token；巨大激活则被解释为帮助形成这种注意力行为的工具。这些说法各有道理，但都站在前向传播的立场上。

1.2 前向解释的死角#

　　问题出在现代架构的细节上。今天的主流模型几乎都是 pre-norm 结构：注意力和 MLP 子层看到的都是归一化后的输入。归一化把输入的尺度抹平了，子层的前向计算主要认方向不认范数。这样一来，“残差流里某个 token 的范数巨大"这件事，在前向路径上几乎不起直接作用，它的存在就显得来路不明。

　　更麻烦的是，已有研究里不少干预实验是拿训练好的模型动刀，修改 MLP 输出或激活值。这类手术往往同时改变了数值的大小和方向，想据此断定巨大激活与注意力汇之间的因果链条，证据链并不干净。

　　于是留下一个训练层面的谜题：标准的 pre-norm Transformer，为什么会在训练中学会如此极端的激活？

1.3 本文的答案：去反向传播里找#

　　这篇论文换到反向传播的立场。它的核心洞察一句话：残差流的尺度在前向不起眼，在反向却握着开关，因为它决定梯度能以多大的幅度穿过归一化层传回深处。而这个开关恰好在 sink token 处被按到最大。

　　因果链条随后展开：因果掩码之下，大量后文 token 把注意力压在 sink token 上，反向传播时它们的训练信号也顺着同一条路汇聚回 sink token，形成梯度的局部洪峰，论文称之为梯度汇（gradient sink）。而 RMSNorm 的雅可比有一个天然性质，梯度增益大约与输入范数成反比。于是巨大激活有了新的身份，它是训练自己学出来的泄压阀：激活范数越大，回传的梯度被压得越狠，正好抵消梯度汇带来的局部高压。

　　这个解释还给出了一个可检验的预言：如果用别的办法泄掉 sink 处的梯度压力，模型就不那么需要巨大激活了。论文用一个叫 V-scale 的干预验证了它，细节在第 5 节一笔带过，本文的主线是机制本身。

2. 机制主线：从注意力汇到梯度汇#

2.1 注意力权重是双向路由器#

　　先立一个简单的事实。单看一个注意力头，写 $A = (a_{tj})$ 为因果注意力矩阵，$V$ 为各位置的 value 状态，头输出就是 $Y = AV$。反向传播从上游梯度 $G = \nabla_Y \mathcal{L}$ 出发，value 通路上的梯度有一个干净的闭式：

$$ \nabla_V \mathcal{L} = A^{\top} G, \qquad \nabla_{v_s} \mathcal{L} = \sum_{t \ge s} a_{ts} \, g_t $$

　　其中 $g_t$ 是位置 $t$ 的上游梯度。这个式子说的是：注意力权重在前向按列汇聚 value，在反向按同一张表汇聚梯度。注意力是一个双向路由器。前向的 sink 意味着 $A$ 的某一列（sink 列）被大量后文行压了重兵；反向时 $A^{\top}$ 的对应行会把这些后文的梯度统统收进同一个早期 token。前向的注意力汇，就这样变成了反向的梯度汇。

2.2 梯度汇：首 token 的梯度洪峰#

　　论文给梯度汇下了个可测量的定义。固定一层，取 sink 位置 $s$（通常为首 token）和一组早期 token 作参照，梯度汇比值是：

$$ R_{GS}(s) = \frac{\| \nabla_{\tilde{h}_s} \mathcal{L} \|_2}{\frac{1}{T_e} \sum_{t \le T_e,\ t \ne s} \| \nabla_{\tilde{h}_t} \mathcal{L} \|_2} $$

　　分子是 sink token 在归一化输入处的梯度范数，分母是其余早期 token 的平均。比值远大于 1，就说明该位置是梯度汇。

　　实测结果相当整齐。无论是在 C4 上从零训练的 0.1B 至 1B 基座，还是 Qwen2.5-7B、Qwen3-8B、Llama-3.1-8B、GLM-4-9B 这些开源模型，首 token 的梯度范数都比早期 token 的均值高出一到两个数量级，$R_{GS}(0)$ 的中位数普遍落在 10 至 100 的区间。梯度汇是训练 Transformer 语言模型时的常见地貌。

2.3 梯度的三条通路不对称#

　　梯度汇长什么样，还得看它从哪条路来。进入注意力子层的梯度会拆成 query、key 和 value 三条通路。逐层统计它们的逐 token 范数，可以看到一个清晰的不对称：

Query 通路Key 通路Value 通路

　　key 与 value 通路在首 token 有显著尖峰，之后迅速回落并保持平坦，且 value 一侧的尖峰始终更大；query 通路则平缓得多。query 通路还有个精确的小事实：因果掩码下首 token 的 query 梯度恒等于零，因为它后面没有任何 token 需要它提供信息。梯度汇的载重主要压在 key 与尤其 value 通路上，这为后文的干预指明了靶子。

2.4 sink 统计量控制梯度压力#

　　尖峰的大小可以被 sink 的"注意力账目"定量控制。记 $M_s$ 为所有后文 token 压在 sink 列上的注意力总质量，$S_s$ 为其平方和（二阶矩）。论文的定理 1 给出 value 路梯度二阶矩的双边界。把后文各位置的上游梯度分解为共同分量 $\mu$ 加噪声 $\varepsilon_t$（噪声方差有界、相关性有界），则：

$$ M_s^2 \| \mu \|_2^2 \le \mathbb{E}_A \left[ \| \nabla_{v_s} \mathcal{L} \|_2^2 \right] \le M_s^2 \| \mu \|_2^2 + \sigma^2 S_s + \rho (M_s^2 - S_s) $$

　　打个比方，sink 列像一条收税的主干道：后文每一笔训练信号路过都要按 $a_{ts}$ 的比例留下一份。只要各路信号有共同的朝向（$\mu$ 非零），收上来的总量就按 $M_s^2$ 增长，注意力账目越大，下界抬得越高。第 2.2 节看到的首 token 尖峰，落在这个式子里就是 $M_s$ 一枝独秀的直接后果。

3. RMSNorm：把激活尺度变成梯度调节器#

3.1 定量：梯度增益约与输入范数成反比#

　　压力有了，接下来看泄压的机制。pre-norm 块里，残差流 $x$ 先过 RMSNorm 再进子层。RMSNorm 的定义是 $\mathrm{RMSNorm}(x) = \gamma \odot x / \mathrm{rms}(x)$，$\gamma$ 是逐维缩放参数。反向传播要穿过它的雅可比矩阵，论文的定理 2 给出这个雅可比的算子范数上界：

$$ \left\| J_{\mathrm{rms}}(x) \right\|_{\mathrm{op}} \le \frac{\| \gamma \|_\infty}{\mathrm{rms}(x)} $$

　　含义直白：输入的均方根越大，梯度穿过去时被削得越狠，增益大致按 $1/\mathrm{rms}(x)$ 衰减。于是对任意期望的梯度上限 $\tau$，只要激活范数满足

$$ \mathrm{rms}(x) \ge \frac{\| \gamma \|_\infty}{\tau} \, \| g_y \|_2 \quad \Longrightarrow \quad \| \nabla_x \mathcal{L} \|_2 \le \tau $$

　　回传到更早层的梯度就被控制住了。这两行就是"巨大激活是梯度调节器"的全部数学内容：在 pre-norm 架构里，一个 token 的激活范数是现成、局部且可学习的梯度旋钮。哪个 token 被梯度汇压得喘不过气，把它的激活撑大就能泄压。

3.2 实测佐证：Bloat、Change、Compress#

　　论文在真实模型里把这条反向通道逐段测了。固定一层一个 token，$g_1$ 是残差相加处的梯度，$g_2$ 是归一化输入处的梯度，$g_3$ 是经 RMSNorm 雅可比回传的分支贡献。三个比值各管一段：

$$ \mathrm{Bloat} = \frac{\| g_2 \|_2}{\| g_1 \|_2}, \qquad \mathrm{Change} = \frac{\| g_1 + g_3 \|_2}{\| g_1 \|_2}, \qquad \mathrm{Compress} = \frac{\| g_3 \|_2}{\| g_2 \|_2} $$

Bloat：分支内放大Change：残差流净变化Compress：RMSNorm 压缩

　　左侧，激活范数巨大的点几乎全部来自首 token，它们正是分支内梯度被放得最狠的位置，高 Bloat 的隐患确实存在。中间，残差流上的净变化 $\mathrm{Change}$ 却紧紧聚在 1 附近，梯度洪峰并没有在残差流里肆虐。右侧给出原因：激活范数越大，$\mathrm{Compress}$ 越小，放得最狠的位置也被压得最狠。放大与压缩在同一个 token 上抵消，残差流的梯度运输保持平稳。

4. 合流：巨大激活是自适应泄压阀#

　　把前四节的零件拼起来，论文的机制主张就是一张完整的因果图：

  1. 因果掩码下，注意力汇把大量后文注意力压在 sink token 上；
  2. 反向传播沿同一张路由表汇聚梯度，sink token 承受局部高压，形成梯度汇（定理 1 量化了压力的来源）；
  3. RMSNorm 让激活范数成为可用的局部衰减因子（定理 2），撑大激活就能压低回传梯度；
  4. 训练于是学会了在 sink token 上长出巨大激活，用它吸收压力、稳住残差流的梯度运输。

　　这个解释的妙处在于它换了一个问法。前向视角问"巨大激活有什么用”，得到的答案往往牵强，因为 pre-norm 下它前向确实没多少用；反向视角问"训练中哪里有压力、模型有哪些泄压手段"，巨大激活就成了最顺手的那一招。它是病灶处长出的老茧。

5. 验证一笔带过：V-scale 干预#

　　机制给出一个可证伪的预言：换一条路泄掉 sink 处的梯度压力，模型就不该再依赖巨大激活。论文设计了 V-scale 来做这个实验，它在 value 聚合前对每个 value 状态乘一个径向缩放 $\hat{v} = \phi(\|v\|_2^2)\, v$，$\phi(r) = r / (r + C)$。对 sink token 这类 value 范数偏小的位置，这个映射的雅可比会强烈衰减其回传梯度，相当于在 value 通路上装了一个梯度阀门；配套的 backward-only 对照用 stop-gradient 技巧保证前向数值完全不变、只改反向规则，把"改梯度"与"改前向"两件事分开。

　　结果与预言一致。0.3B 规模上梯度汇中位数从 40.3 降到 5.6；注意力汇被完整保留，部分层甚至略有增强；巨大激活显著消退，尤其在 MLP 输出上，而 V-scale 对 MLP 前向并无直接缩放，消退只能来自训练动力学的改变。backward-only 对照复现同样的模式，说明单靠修改反向规则就足够。下游方面，常规评测与基座相当，多键检索（multi-key NIAH）在全部精度与上下文长度组合上占优，8192 长度下提升 8.7 至 15 个百分点；在静态激活量化的高压设置下，基座的检索近乎归零，V-scale 仍保有可观的准确率。

6. 冷静看局限#

　　对该机制的适用范围与证据强度，仍有几点需要如实评估。

　　第一，实验对象限于 decoder-only 稠密模型。MoE 架构与多模态 Transformer 是否遵循同一机制，论文未作回答，仅将其列为未来工作。第二，机制的直接因果证据目前仅来自 V-scale 一组干预实验。散点测量提供的是相关性证据，定理给出的是条件性的界；干预本身也并非单因素操作，它同时改变了 value 的前向收缩与反向雅可比的谱性质，backward-only 对照虽将两者部分分离，却未能穷尽混淆因素。论文亦明确指出，数据分布、优化器与数值精度均可能参与这两个现象的形成。

　　第三，大模型上的梯度测量来自诊断批次上的事后探针，并非其真实训练过程中的梯度；从零训练的对照实验仅至 1B 规模，机制在更大规模与更长训练下的稳定性尚待验证。此外，$R_{GS}$ 的取值依赖测量协议，包括批次聚合方式、参照 token 区间与阈值设定，跨模型比较宜着眼于量级而非精确数值。最后，V-scale 的下游收益与机制主张之间仍缺少一环：多键检索的提升与巨大激活的消退同时发生，但"泄压带来检索能力"的因果路径尚未闭合。论文也指出，所学 V-scale 参数随层、随头的变化如何影响性能，有待更细致的分析。

7. 总结#

　　这项工作为两个长期共存的现象提供了统一的解释。注意力汇与巨大激活的关联不在前向传播，而在反向传播：因果掩码使 sink token 成为梯度的汇聚点，RMSNorm 提供了以激活范数调节梯度增益的机制，巨大激活由此可以理解为训练过程中形成的梯度调节器。V-scale 的干预实验进一步支持了这一解释，抑制 sink 处的梯度压力之后，巨大激活显著减弱，注意力汇则基本不受影响。

　　这一视角的价值可以延伸到两个方向。就可解释性研究而言，它提示前向传播中部分难以解释的现象，或许可以在反向传播中找到更为简洁的答案。就训练与部署工程而言，量化敏感性实验表明，训练阶段形成的梯度调节有助于提升模型对激活量化的鲁棒性。训练动力学与推理精度之间的这类联系，值得进一步探究。
